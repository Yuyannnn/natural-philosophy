<a id="source-L65"></a>古典物理学の描く世界像  
<a id="source-L66"></a>近代物理学は１９世紀頃にできた古典物理学、２０世紀の登場し今も発展途上である量子力学と相対論よりなる。  
<a id="source-L67"></a>高校で学ぶ古典物理学は全ての基礎なので、自由に扱えるようにしておく必要がある。  
<a id="source-L68"></a>「３次元の一様・等方な空間の中で、一様な時の流れの下での、極めて多数の点粒子の運動が自然現象であり、この関係が空間的、時間的にも局所的に定まると考える」  
<a id="source-L69"></a>空間の一様性: 空間の任意の移動に対し、空間自体になんの違いもないという不  

> > > > > > > > > > > > > > <a id="source-L70"></a>変性。  

<a id="source-L71"></a>空間の等方性: 空間における任意の回転に対し、空間自体になんの違いもないと      

> > > > > > > > > > > > > > <a id="source-L72"></a>いう不変性。  

<a id="source-L73"></a>時間の一様性: 時の移動に対し、時の流れ方に違いがないという不変性。  

<a id="source-L75"></a>空間の一様性、空間の等方性、時間の一様性、を仮定しないと後に出てくるエネルギー保存則が成り立たなくなってしまう。  

<a id="source-L77"></a>質点の運動の表現  
<a id="source-L78"></a>難しい関数でも微小な区間で考えると関数が直線と近似できることができ、xとyの比例関係で扱えるので dy=（接線の傾き）×dx である。  
<a id="source-L79"></a>難しい関数を直線で近似するというのが微文法の考え方である。  
<a id="source-L80"></a>積分は微小長方形を足すという概念で、f(x)の原始関数を見つけることができれば簡単に計算できる。  
<a id="source-L81"></a>大きさや向きの扱いやすさから物理では通常、正規直交基底を用いる。  
<a id="source-L82"></a>物理量の関係は厳密にdx=vdtとdv=adtであり、これらからvdv=adxが導ける。  
<a id="source-L83"></a>物理量を考えるときは次元解析を行うのが普通で、単位を考える。  

<a id="source-L85"></a>２次元運動  
<a id="source-L86"></a>２次元運動の軌道は初速度//加速度のときは、それ以外のときは放物線である。  
<a id="source-L87"></a>最高点や水平到達距離は常識にしておく。  
<a id="source-L88"></a>相対運動を考えるとき、２つ以上のものが動いていたら片方からの相対速度を想像するのは難しいので、数学的表現にもちこむ。  
<a id="source-L89"></a>地上付近で投げられた２物体の相対加速度は０なので、相対運動は等速直線運動になる。  
<a id="source-L90"></a>モンキーハンティング問題などは常識にしておく。  


<a id="source-L93"></a>運動方程式  
<a id="source-L94"></a>一様・等方空間、一様時間のもとでは、孤立した粒子が静止を続ける座標系を選べる。この座標系を慣性系という。  
<a id="source-L95"></a>粒子は他の粒子の影響を受けて運動が変わるというのがニュートン力学のモデルである。  
<a id="source-L96"></a>簡単な系を考えると、系の粒子の位置と速度を与えるとその後の運動は定まるように思える。  
<a id="source-L97"></a>これが一般的に成り立つとすれば粒子の加速度が系の粒子の位置や速度の関係として決まっていることになる。  
<a id="source-L98"></a>この関数関係を運動方程式という。  
<a id="source-L99"></a>簡単なときを考えると、同じ影響を受けたと思われるときでも、粒子によりその加速度は違うようである。そこで、粒子のもつ基本性質として加速度の生じにくさ（運動の変化のしにくさ）があると考えられ、この性質を慣性質量という。

### 4. ④	弱い力

<a id="source-L110"></a>強い力と弱い力は原子を構成する素粒子レベルの小さな物体に働く力なのでニュートン力学では考えてなくてよい。  
<a id="source-L111"></a>よってニュートン力学では重力と電磁気力を考えれば力は尽くされる。  
<a id="source-L112"></a>重力は、考えている物体が地球から受ける重力以外は弱すぎて無視できる。

<a id="source-L121"></a>慣性力

<a id="source-L124"></a>ある加速で動く座標でみると、慣性系でみた加速度に加えある加速度が合成されて見える。これを説明するために本来の相互作用以外に（考えている物体の質量）×（余分な加速度）＝（余分な力）が加わったとして考えることができ、これをみかけの力（慣性力）と呼ぶ。
