### 第1章 有限要素法の基礎知識


<a id="source-L19"></a>

### 1.1 材料力学とは

<a id="source-L20"></a>材料力学とはいくつかの単純な仮定を置くことにより非常に簡単な式で部材の変形や内部の応力・歪みを近似的に表現することを可能にする力学である  


<a id="source-L22"></a>

### 1.2 有限要素法とは

<a id="source-L23"></a>有限要素法では、同じ梁の問題を解析対象領域を節点で囲まれたメッシュ状の領域に分割し、変形を近似的に解く  
<a id="source-L24"></a>ある要素ないの変異分布は節点の変位の値を使った形状関数によって内挿された値で近似される  
<a id="source-L25"></a>そして代表点である節点の変異の数値計算で求める  
<a id="source-L26"></a>隣り合う要素は節点によって共有されているので、どのように結合しているかが計算に反映される  

<a id="source-L28"></a>ポイント１  
<a id="source-L29"></a>有限要素法ではある要素内の変位分布は節点の変位の値を使った形状関数によって内挿された値で近似される、そして代表点である節点の変位を数値計算で求める  
<a id="source-L30"></a>結果は節点数に大きく依存する  


<a id="source-L32"></a>

### 1.3 材料力学と有限要素法

<a id="source-L33"></a>材料で扱える構造は近似が成り立つ限られた理想的な形状であり、汎用性に欠ける  
<a id="source-L34"></a>しかし、材料力学の解を求める意義は大きい、というのもオーダーエスティメーションができる  
<a id="source-L35"></a>特に有限要素法との関係において引っ張り・圧縮・曲げ・ねじり・座屈の概念の理解は重要である  
<a id="source-L36"></a>また、結果の解釈においては応力ー歪み関係式、応力テンソルの理解も必須である  
<a id="source-L37"></a>また、必ず実機の応力や変位との比較によって検証されなければならない

### 第4章 有限要素法の実践的知識

<a id="source-L101"></a>有限要素法の使用にあたっては高度な実践的知識が必要となるので、この章では、適正な形状のモデリング、要素の選定、メッシュ分割の工夫、環境条件の設定、物理モデルの設定・材料物性の入力、解析の結果の検証、分析と解釈、強度設計について詳細に記した

[原文63行目](#source-L63)は線形静解析の一例として読む。有限要素法は一般に「逆行列を掛ける手順」という定義ではなく、弱形式を有限次元の空間で近似する方法。実装では境界条件を適用して $Ku=f$ を解き、通常は逆行列を明示的に作らない。

「三角形一次要素は使われない」という断定も避けたい。公式の[Poisson方程式の例](https://docs.fenicsproject.org/dolfinx/main/python/demos/demo_poisson.html)でも三角形・一次要素を使用している。精度は問題、解の滑らかさ、要素次数、メッシュ品質などと合わせて評価する。実機との比較という原文の観点は、数値解の収束確認と別に残す。
