# 参考文献 / References

本、論文、講義、Web資料の書誌情報と読書メモを置きます。概念の説明は各分野のノートに書き、ここでは資料の所在と、どこを読んだかを残します。

- ファイル名：`author-short-title.md`。衝突する場合は年や版を加える。
- 書籍：著者、書名、版、出版年、参照した章・節・ページ。
- 論文：著者、題名、掲載先、年、DOIまたはURL、参照箇所。
- Web・講義：著者または提供者、題名、URL、公開・更新日（わかる場合）、閲覧日。

ノートの重要な主張から、参照した資料と該当箇所をたどれるようにします。資料が少ない間は、ノート末尾に直接書誌情報を書くだけでも構いません。

本文の転載ではなく、書誌情報、自分の要約、必要な範囲の引用を保存します。読んでいない資料を、確認済みの根拠として登録しません。
