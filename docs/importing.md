# Scrapbox・Notionからの取り込み

元のメモの問いと文脈を保ちながら、公開して読めるMarkdownのノートに整えます。原文の保管と公開用の編集を分けます。

## 1. 原文を置く

エクスポートしたファイルやコピーした文章を、ローカルの `inbox/` に置きます。たとえば `inbox/notion/2026-09-20/` のように取り込み元と日付でまとめます。このフォルダは `.gitignore` でGit管理対象から除外しています。

原文は編集せず残します。元ページのタイトル、URLまたは識別子、取り込み日をローカルのメモに控えると、後から照合できます。非公開URLや識別子を公開ノートに転記する必要はありません。

今回の数学メモは、ユーザーから公開ページの全文移植と意図の保存を明示的に依頼されています。その範囲では `math/sources/` に本文の原文テキストも置き、読みやすく整形したノートと行単位で照合できるようにしています。非公開素材の取り込みとは区別します。

`.gitignore` はGitの追跡対象を制御する設定であり、アクセス制御や匿名化ではありません。すでに追跡したファイル、強制追加したファイル、Gitを使わないアップロードには別途確認が必要です。

## 2. 既存ノートと照合する

原文を読む前後に、各分野の入口と関連ノートを確認します。同じ概念があれば、重複する新規ノートではなく既存ノートへの追記を検討します。一つの原文から複数ノートを作る場合も、前提と結論が離れて意味が変わらないようにします。

## 3. 公開用に書き直す

[ノートのひな形](../templates/note.md)を使い、問い、前提、説明、具体例、出典を整理します。原文にない補足は、確認した出典を添えるか、未確認の補足として区別します。矛盾や疑問を、滑らかな文章で隠さないようにします。

全文移植では、まず「当時の本文」に原文の順序・言葉・感想・疑問・空白を残し、別の節でAIによる補足や訂正を加えます。短いリンクメモに、読んだことのない内容や感想を本人の文章として補作しません。図・数式の欠落も位置を記録し、推測で埋めたものを原文と混ぜません。

元サービスのページリンクは、対応するノートが存在すれば相対リンクに置き換えます。リンク先が未取り込みなら、公開可能な元ページへのリンクか、リンクなしの用語として残します。未作成のファイルにリンクしません。

画像・添付・数式・表は、文章とは別に欠落や崩れがないか確認します。添付ファイルは、必要性と公開できる内容かを確認してから `assets/` にコピーします。

## 4. 確認して配置する

公開用の内容を[執筆ガイド](writing.md)に沿って確認してから、該当する分野へ置き、入口と関連ノートにリンクを追加します。内容と出典の人による確認が済んだ場合だけ `status: reviewed` にします。未解決の問いがあるノートも、何が未解決かを明記して公開できます。

## AIへの依頼例

```text
inbox/ にある指定のメモを、AGENTS.mdとdocs/のガイドに沿って整理してください。
原文は保持し、公開候補をまず inbox/drafts/ に作ってください。
既存ノートと重なる部分は追記案にしてください。
定義・前提・出典・未確認事項を分け、補足は元の文章と区別してください。
リンクや添付の欠落、意味が変わった箇所があれば報告してください。
```

公開先への配置まで依頼された場合は、その範囲で進めます。原文が手元にない段階で、取り込み済み・確認済みとは扱いません。

## 今回の数学移植を検証する

`python3 scripts/import_scrapbox_math.py --check` で、公開ファイルだけを使い、原文と移植本文のチェックサム、全行の対応、ローカルリンク、画像のチェックサムを確認します。新しくcloneした環境でも実行でき、検証にネット接続や追加パッケージは不要です。

ローカルに `inbox/scrapbox/2026-09-20/math-full/` のAPI応答があれば、取得した原文および再変換した本文との一致も追加で確認します。再生成（`--check` なし）には、このAPI応答と同階層の取得時のカタログ・画像情報が必要です。公開manifestのチェックサムは移植時点との整合性を確認するもので、原文の内容が正しいことや第三者による真正性の保証ではありません。

移植先と補足文の設定は `scripts/math_import_content.py` にあります。生成スクリプトは既存の手編集を検出した場合に停止します。通常は `--overwrite` を使わず、本人の追記を保って変更してください。今回の取得はページのスナップショットであり、Scrapboxの全改訂履歴や削除済み内容の取得ではありません。

## 物理編の取り込み

物理編も同じ全文保存の方針で、physics/sources/に公開原文を保存しています。[物理の移植記録](../physics/import-report.md)に対象の51ページ、追加した理由、訂正箇所、欠落を記しました。

~~~sh
python3 scripts/import_scrapbox_physics.py --check
~~~

数学と物理の変換・検証処理はscripts/scrapbox_import.pyを共用し、科目ごとの設定と補足は別ファイルに置きます。物理の再生成にはinbox/scrapbox/2026-09-20/physics-full/の取得時API応答・画像情報が必要ですが、検証は公開ファイルだけで動きます。数学側の既存原文を物理へ複製せず、科目をまたぐ相対リンクでつなぎます。
