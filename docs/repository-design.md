# 構成の参考にしたリポジトリ

公開された学習ノートや技術書の構成を調べ、このノートを読み続け、更新しやすくするための参考にしました。2026-09-20時点のREADMEとファイル構成を確認しています。

- [jbranchaud/til](https://github.com/jbranchaud/til)：日々の小さな学びを短い文書にし、分野別の索引から読める構成。一つの問いを一つのノートにまとめ、各分野のREADMEからたどる方針の参考にしました。
- [simonw/til](https://github.com/simonw/til)：トピック別のMarkdownを蓄積し、READMEから個々の記録に案内しています。通常のファイルで学びを残し、後から見つけられるようにする考え方を参考にしました。
- [cyrus2281/notes](https://github.com/cyrus2281/notes)：数学・機械学習・論文のノートと、学習資料の一覧を分けています。ここでも本文、参考文献、原文の役割を分け、相互にリンクしています。
- [d2l-ai/d2l-en](https://github.com/d2l-ai/d2l-en)：数式・説明・実行可能なコードを組み合わせた教材で、執筆や貢献のガイドも用意されています。ノートに対応する小さな実行例と、修正を提案するための案内を設ける参考にしました。

## このノートで大切にすること

入口には代表的なノートと分野別の索引を置きます。長い過去メモは当時の文脈ごと保持し、そこから取り出した問いを、別の説明ノートで掘り下げます。短いノートという形式を、移植元の文章を削る理由にはしません。

原文とAIの補足、過去の疑問と現在の理解を区別します。原文のチェックサムや行の対応を残し、出典へ戻れるようにします。自動チェックで確かめるのは保存とリンクの整合性であり、内容の数学的な正しさとは区別します。

フォルダは内容が増えたときに育てます。物理学・化学は入口から始め、学びが集まる前に細かい分類を大量に作らない方針です。
