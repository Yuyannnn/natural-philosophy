# 数学 / Math

Scrapboxに蓄積してきた数学のメモを、当時の言葉と考えた道筋を残しながら整理しています。計算の方法だけでなく、何に驚き、何がわからず、どの分野へつなげたかったのかも読み返せる場所にします。

**2026-09-20に公開を始めた、整理途中のノートです。** 現在は過去のメモの移植が中心で、ここから文章・構成・出典を見直し、具体例や考察を増やしていきます。[全体の方針](../README.md)も参照してください。

数学欄の全45ページと関連19ページ、計64ページの本文を移植しました。各ノートは**当時の本文**と**今回のAIによる補足・訂正**を分けています。読み直しのために原文を残しているので、古い表記や未完成の説明もあります。
