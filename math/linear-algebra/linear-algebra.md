<a id="source-L36"></a>基本変形  
<a id="source-L37"></a>線形代数学の目標は行列の性質をよりよく理解できるようになること。  
<a id="source-L38"></a>まずは、計算のパートとして、行列を数が並んだものとして、行列に対する理解を深めることが大切になるが、このための2大柱が基本変形と行列式である。  

<a id="source-L40"></a>・基本変形とは  
<a id="source-L41"></a>基本変形とは、与えられた行列Aに対して、  
<a id="source-L42"></a>(1)ある２つの行を入れ替える  
<a id="source-L43"></a>(2)ある行に別な行の何倍かを足す  
<a id="source-L44"></a>(3)ある行を何倍かする  
<a id="source-L45"></a>という３種類の操作を行に関する基本変形と呼び、列に対しても同じように存在する  

<a id="source-L47"></a>・基本変形と基本行列の対応  
<a id="source-L48"></a>行に関する基本変形は行列を左から掛け算することにより実現でき、列に関する基本変形は行列を右から掛け算することにより実現できる  
<a id="source-L49"></a>基本変形に関して大切なことは、単に基本変形の手続きを覚えるのではなく、行や列に関する基本変形を施すことは対応する基本行列を左や右から掛け算することで実現されることをしっかりと理解することである  

<a id="source-L51"></a>・行列のrankとは  
<a id="source-L52"></a>行列のrankとは、Aは行や列に関する基本変形を施して見やすい形に変形させられる。  
<a id="source-L53"></a>見やすい形の対角線上に残った1の数の行列Aの階数と呼び、Aのrankは行列Aを掛け算する写像の大まかな様子を教えてくれる基本的な不変量である  

<a id="source-L55"></a>・基本変形を用いた逆行列の計算法  
<a id="source-L56"></a>AのよこにIを並べてBとし、Bに行変形だけを施してAをIにすること考えると、IはAの逆行列になっている  

<a id="source-L58"></a>・基本変形を用いた連立一次方程式の解法  
<a id="source-L59"></a>行変形だけで見やすい形に書き換える。  
<a id="source-L60"></a>解集合は変わらないので、見やすい形の行列を解けば良い。  




<a id="source-L65"></a>行列式  
<a id="source-L66"></a>一般に、正方行列に行列式と呼ばれる数を対応させることができる  

<a id="source-L68"></a>・行列式の幾何的な意味  
<a id="source-L69"></a>行列式を、a1\~anのn個のベクトルを変数とする関数として考察することが大切なポイントとなる  
<a id="source-L70"></a>すると、行列式は、符号付き面積を対応させる関数であることがわかる  

<a id="source-L72"></a>・行列式を特徴づける３つの性質  
<a id="source-L73"></a>(1)多重線形性  
<a id="source-L74"></a>(2)歪対称性(交代性)  
<a id="source-L75"></a>(3)規格化条件  
<a id="source-L76"></a>符号付き面積や体積は上の３つの性質を持つことを納得することが大切である  
<a id="source-L77"></a>また、その値は３つの性質を用いて完全に計算できてしまうことを納得する  
<a id="source-L78"></a>計算結果が教科書に載っている行列の定義式である  

<a id="source-L80"></a>・行列式の持つ基本的な性質  
<a id="source-L81"></a>(1)(2)という性質を持つ関数は行列式の定数倍しかないという事実を使うと、  
<a id="source-L82"></a>det(AB) = det(A)det(B)  
<a id="source-L83"></a>det(AB) = det(BA)  
<a id="source-L84"></a>det(P-1AP) = det(A)  
<a id="source-L85"></a>がわかる  
<a id="source-L86"></a>３つ目は、概念のパートで重要な役を果たす  

<a id="source-L88"></a>・行列式の展開公式  
<a id="source-L89"></a>左上の対角線上に1が１つだけある行列はそれを省いてもおk  
<a id="source-L90"></a>これを利用すると、いろんな行列を展開できる  
<a id="source-L91"></a>また、列と行どちらでも展開できることがわかる  
<a id="source-L92"></a>いきなり展開公式を使うのではなく、行や列に関する基本変形を行ってある行あるいはある列になるべくたくさん０が登場するようにしてから展開公式を用いるのが良い  

<a id="source-L94"></a>・余因子展開とCramerの公式  
<a id="source-L95"></a>一般にn行n列の行列Aに対して、i行目とj列目だけを1で十字形に0を並べた行列式を行列Aの第(i,j)余因子と呼ぶ。  
<a id="source-L96"></a>余因子を用いると行列式の展開公式を簡単に表せる  
<a id="source-L97"></a>行列Aの第(i,j)余因子をj行i列とする行列を余因子行列と呼ぶ  
<a id="source-L98"></a>このとき,AA(余因子行列) = detA Iとなる  
<a id="source-L99"></a>逆行列が存在するための必要十分条件はdetA not 0である。  
<a id="source-L100"></a>行列式が0じゃないときは、上記の式を行列式で割れば逆行列の公式(Cramerの公式)の出来上がり

<a id="source-L198"></a>線形空間と線型写像  
<a id="source-L199"></a>行列とは見方を変えるとコロコロ姿を変えるものであり、最初に与えられた姿ではなく、見やすい形になるような視点から眺めてやることでよりよく理解できるのではないかという作戦が概念のパートの話である  
<a id="source-L200"></a>姿を変えるというような言明が意味を保つためには行列を数が並んだものではなく別の視点から眺める必要が出てくる  
<a id="source-L201"></a>この目的のために導入されたものが線形空間と線型写像である  

<a id="source-L203"></a>・線形空間とは  
<a id="source-L204"></a>最初に与えられた姿に騙されずに行列のことを理解するためのアイデアは、数ベクトル空間から座標系を外して眺めるという視点を導入することである  
<a id="source-L205"></a>座標は具体的な計算を進める上で便利であるものの、物事の本質には関わっていないと思われる。  
<a id="source-L206"></a>数ベクトル空間から座標軸を外してみると、原点のある真っ直ぐな空間が残るように思われるが、原点のある真っ直ぐな空間こそが線形空間である。  
<a id="source-L207"></a>足し算やスカラー倍ができるということが数学的に言い換えであると考えて、これらができる空間を線形空間と定義する。  

<a id="source-L209"></a>・線形部分空間とは  
<a id="source-L210"></a>一般に線形空間の部分集合が、線形空間と同じような性質を満たすとき、それを線形部分空間であるという  

<a id="source-L212"></a>・線型写像とは  
<a id="source-L213"></a>行列を数が並んだものとしてではなく、別の視点から眺めてみるというのが概念のパートにおける基本的な考え方  
<a id="source-L214"></a>そのためのアイデアは、行列を掛け算する操作に注目するということ  
<a id="source-L215"></a>２つの条件を満たすときに写像fを線型写像という  
<a id="source-L216"></a>つまり行列を掛け算する操作は線型写像であると考えられる  

<a id="source-L218"></a>・数ベクトル空間の間の線型写像と行列の関係  
<a id="source-L219"></a>一般にm行n列の行列Aに対して、行列Aを掛け算する操作  
<a id="source-L220"></a>fa:Rn → Rm  
<a id="source-L221"></a>は線型写像になることが分かるが、逆にRnからRmへの線型写像はこのようなものしか存在しないことが分かる  
<a id="source-L222"></a>すなわち、fを線型写像とすると、それはm行n列の行列で表せるということ  
<a id="source-L223"></a>またAがBでないとすると、写像としてもAがBでないということが分かる  
<a id="source-L224"></a>つまり、数ベクトル空間の間の線型写像とは行列を掛け算する操作に他ならないことが分かる  
<a id="source-L225"></a>数が並んだものとしての行列Aを掛け算する操作と同一視して考えることにより行列Aを座標系によらずに眺める視点が獲得できたことになる  



<a id="source-L229"></a>線形空間の番地割り  
<a id="source-L230"></a>線形空間や線型写像という概念を導入することにより、行列Aを座標軸によらずに眺める視点が得られることになる

<a id="source-L590"></a>実際に計算を行ってみると、Jordan標準形の相異なる固有値をλ1,,,λLとして、それぞれの固有値に対して最もサイズの大きなJordan細胞をJm1,,,Jmlとすると、  
<a id="source-L591"></a>ψJ(x) = (x-λ1)^m1(x-λ2)^m2,,,となることが分かる  
<a id="source-L592"></a>よって正方行列Aに対して、行列Aの最小多項式を求めることによりそれぞれの固有値に対応する最もサイズの大きなJordan細胞の情報が得られるということが分かる  






<a id="source-L599"></a>Jordan標準形の応用例  
<a id="source-L600"></a>見やすい形の行列として、Jordan標準形を採用することにより行列の標準形の問題をいつでも解決できることを見ましたが、Jordan標準形の知識を用いてすっきりと理解することができる代表的な例として、数列に対して定数係数の線型漸化式と関数に対する定数係数の線形微分方程式がある  

<a id="source-L602"></a>・数列に対する定数係数の線型漸化式  
<a id="source-L603"></a>漸化式を線形代数学の立場から見直すためのアイデアは「(an-1, an-2)からanが決める」と読まずに、あえて「(an-1,an-2)から(an,an-1)が決まる」というように読み替えることです  
<a id="source-L604"></a>この考え方により、「定数係数の漸化式を満たす数列の一般項を求める問題」が「A^nという行列Aのn乗を求める問題」に帰着することが分かる  
<a id="source-L605"></a>ここで、Jordan標準形を用いると、A^n = PJ^nP-1としてA^nが求められる  

<a id="source-L607"></a>・関数に対する定数係数の線形微分方程式  
<a id="source-L608"></a>定数係数の線型常微分方程式を線形代数学の立場から見直すためのアイデアは、あえて「(f’,f)から(f’’,f’)が決まる」と読み替えることである  
<a id="source-L609"></a>すると、微分方程式が一階の常微分方程式の形に書き直すことができることが分かる  
<a id="source-L610"></a>つまり、定数係数の線型常微分方程式の解を求める問題が、微分するとA倍される関数を求める問題に帰着することが分かる  
<a id="source-L611"></a>さらに、この式は、行列の指数関数を導入することにより、具体的に解くことができることが分かる  
<a id="source-L612"></a>よって微分方程式を解く問題が、正方行列Aに対して行列の指数関数を求める問題に帰着することが分かる  
<a id="source-L613"></a>ここで、Jordan標準形の知識を用いると、exp(xA)を求めることができることが分かる  
<a id="source-L614"></a>実際にexp(xA)という行列の行列成分にどのような形の関数が現れるかを知るためには行列AのJordan標準形Jを具体的に求める必要があるが、これは次にようにして求められる  
<a id="source-L615"></a>行列Aの特性多項式はψa(x)で与えられる  
<a id="source-L616"></a>これは形式的には微分方程式においてf(i) を x^iと置き換えることによって得られることが分かる  
<a id="source-L617"></a>さらに、行列Aの最小多項式は常に特性多項式と一致するということもわかる  
<a id="source-L618"></a>そこで、特性多項式が因数分解されるとしたら、最小多項式も同じ因数分解で表される  
<a id="source-L619"></a>すると、最小多項式はそれぞれの固有値に対応した最もサイズの大きなJordan細胞の情報を与えてくれるので、行列Aの標準形にはJm1,Jm2、、などのJordan細胞が登場することが分かる  
<a id="source-L620"></a>これらのJordan細胞を並べた行列を考えてみると、行列AのJordan標準形はこのような式で与えられることが分かる  
<a id="source-L621"></a>また、AのJordan細胞にはそれぞれの固有値に対してちょうど一つのJordan細胞が登場することが分かる  
<a id="source-L622"></a>これらのJordan細胞のサイズを求めるには、特性多項式を因数分解してみれば良いこともわかった  
<a id="source-L623"></a>よって、exp(xJ)がどのような形になるか分かるので、exp(xJm)がもとまれば良いということになる  
<a id="source-L624"></a>ここで、Jordan細胞をべきゼロ行列のように分解してみれば比較的簡単に求めることができる  
<a id="source-L625"></a>以上の結果を用いて、定数係数の線型常微分方程式の解がどのような形をしているのかということを議論してみると、微分方程式の解を求めるために以下のような戦略を立てられることが分かる  
<a id="source-L626"></a>(1)与えられた微分方程式に対してf(i)→x^iという書き換えを行って、行列Aの特性多項式を求めて因数分解する  
<a id="source-L627"></a>(2)(1)で得られた因数分解のパターンから重ね合わせを考える  
<a id="source-L628"></a>(3)初期値を求めて係数を決定する  
<a id="source-L629"></a>このような戦略で微分方程式の解を求めることにすれば正則行列Pを具体的に求めたり、行列の指数関数を計算する必要がなくなるので、物理学の教科書などではこのような開放が説明されていることが多い

<a id="source-L1140"></a>fの全単射性 ⇔ Aの正則性  
<a id="source-L1141"></a>という性質が成り立っている  
<a id="source-L1142"></a>表現というものを考えたとき、表現されるがわの性質が表現に用いた側の性質のどれに対応するかを考えるのが数学である  
<a id="source-L1143"></a>細かな性質を見ていくことでより一層見通しが良くなる  

<a id="source-L1145"></a>二次正方行列全体の集合を一般線形群といいMとかく  
<a id="source-L1146"></a>相似という関係はこのMに同値関係を入れている  
<a id="source-L1147"></a>つまり、ある種の線型写像全体の集合Mに同値類\~を入れて出てくる剰余群の１つ１つが線型写像と一対一に対応していることがわかる  




<a id="source-L1151"></a>

### 4 固有値/対角化



<a id="source-L1153"></a>

### 4.1 行列の固有値と固有ベクトル


<a id="source-L1155"></a>固有値があって固有ベクトルがあることを感じ取る  
<a id="source-L1156"></a>固有値が最終的には議論の中心的役割を満たす  
<a id="source-L1157"></a>定義に従って線形空間における幾何学的な意味を探っていく  

<a id="source-L1159"></a>ある種の機械的操作に何かしらの意味を満たせて理解することは数学的な議論をする上で、重要な役割を果たす  
<a id="source-L1160"></a>しかし、効力が大きい分、難しい  

<a id="source-L1162"></a>線型写像はある方向に線形構造を保ったまま、α倍に伸ばしているということが見えてくる  

<a id="source-L1164"></a>固有空間のベクトルは定数倍しか伸ばさず、それ以外は何もしていないことがわかる  

<a id="source-L1166"></a>伸ばした倍率と伸ばした方向は一対一の対応がついていることがわかる  

<a id="source-L1168"></a>代数学の基本定理によってk固有値の存在を示している  
<a id="source-L1169"></a>従って固有値は複素数になることもある  

<a id="source-L1171"></a>この議論を線型写像に持ち込んでいく  




<a id="source-L1175"></a>

### 4.2 線型写像の固有値とその図形的意味


<a id="source-L1177"></a>線型写像は行列によって表現される  
<a id="source-L1178"></a>そのことを考えると、行列に定義できた固有値や固有ベクトルの議論を導入できて欲しい  
<a id="source-L1179"></a>しかしながら、１つの線型写像の表現は一意に定まるものではなく、相似という関係によって結ばれる様々な行列が表現になっていることもわかった  
<a id="source-L1180"></a>従って、線型写像に固有値や固有ベクトルを定義しよう、行列に関する導入しようと思うと、どの表現行列に関する固有値なのか、ということが問題になる  
<a id="source-L1181"></a>しかし、相似という関係から、固有値が等しいということが出てくる  


<a id="source-L1184"></a>線型写像の表現行列はどれを選んでも固有値、固有ベクトル、固有空間、固有多項式は同じなので１つの表現行列だけ調べれば良い  
<a id="source-L1185"></a>このことから、示唆される線形空間が重要なことがわかる  
<a id="source-L1186"></a>有限次元を見ているので必ず基底が存在する  
<a id="source-L1187"></a>しかし、線型写像の性質を見るために固有空間を調べてみると、そのことは基底によらず定まっていることがわかる  
<a id="source-L1188"></a>なぜ基底によっていないかというと、基底によって表現が変わるが、表現にかかわらず、固有値などが定まっているからである  
<a id="source-L1189"></a>つまり、基底とは無関係に線型写像の性質は定まっているのである
