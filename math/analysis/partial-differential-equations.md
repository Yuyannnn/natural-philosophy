### 「機械系数理工学」


<a id="source-L12"></a>機械工学で現れる様々な微分方程式を系統的に解く手法について，具体的な例題を通して学ぶ．特に，ばね・マス系の振動問題と弦や膜の振動問題を介して，行列の固有値問題から，微分演算子に対する固有値問題を説明していく．そして，固有ベクトルが固有関数の概念へと置き換わり，ベクトルを固有ベクトルで分解することが，関数を固有関数で分解することに対応しているのを理解する．特に，三角関数の基底で表現される通常のフーリエ級数展開に加え，２階の線形常微分方程式に現れる様々な特殊関数が，関数空間の直交基底となっていることを理解することにより，弦の振動と膜の振動の違いなどを理解する．また，そのような解析を行うために必要な数学的スキルを身につける．

### 1.1 偏微分方程式の型

<a id="source-L196"></a>数値計算の方法に注目すると、偏微分方程式は次の３つに分類される  
<a id="source-L197"></a>(1)楕円型：ポアソン方程式  
<a id="source-L198"></a>楕円型の微分方程式は時間微分項を持たない  
<a id="source-L199"></a>境界値問題として解かれる  
<a id="source-L200"></a>離散かして得られる連立一次を解くことにより数値解が得られる  

<a id="source-L202"></a>(2)放物型：熱伝導方程式、拡散方程式、移流拡散方程式  
<a id="source-L203"></a>初期値問題として解かれる  
<a id="source-L204"></a>現在のタイムステップの値を使って繰り返し直後の値を求める  
<a id="source-L205"></a>陽解法では連立一次方程式を解くことなしに直接値を決められる  

<a id="source-L207"></a>(3)双曲型：移流方程式、波動方程式  
<a id="source-L208"></a>初期値問題として解かれる  
<a id="source-L209"></a>拡散項がないため、安定な解を得るのが難しい

<a id="source-L242"></a>偏微分方程式の代表的な３つの型（放物型、楕円型、双曲型）からそれぞれ典型的なケースを取り上げ、その性質を調べる  
<a id="source-L243"></a>理解の助けになるような様々な話をするが、幹となるのはFourierの方法、最大値原理、エネルギー保存則で、問題として適切性である  

<a id="source-L245"></a>(1)波動方程式  
<a id="source-L246"></a>(2)熱伝導方程式  
<a id="source-L247"></a>(3)Poisson方程式  
<a id="source-L248"></a>この３つは次に述べる理由から良い代表例である  
<a id="source-L249"></a>・PDEを３つに分類することができるが、それぞれの典型例となっている  
<a id="source-L250"></a>・簡単であるため取り扱いが容易だが、本質は失われていない  
<a id="source-L251"></a>・物理的な意味を持ち、歴史的にも早い段階で登場した  

<a id="source-L253"></a>この講義ではFourier解析を主な道具として３つの方程式を解析する

### 1.1 波動方程式とは


<a id="source-L271"></a>MaxwellはMaxwell方程式を変形したら、偏微分方程式の形になるから真空中を伝播する電磁波の存在を予言した  

<a id="source-L273"></a>どんな波動現象でも波動方程式で記述できるだけではなく、薄い板の振動は4階の偏微分方程式に従う  


<a id="source-L276"></a>1.2 1次元空間における波動方程式  

<a id="source-L278"></a>・ダランベールの解  

<a id="source-L280"></a>f(x-ct)は正方向に速さcで進む波、g(x+ct)は負方向に速さcで進む波を表している  

<a id="source-L282"></a>ダランベールはこれをどのように見つけたのか？ということは、微分作用素の因数分解に隠されている  

<a id="source-L284"></a>・初期値問題、ダランベールの波動公式  
<a id="source-L285"></a>解は無限に存在し、解を１つに特定するためには他の条件を追加しなければならない  
<a id="source-L286"></a>代表的なものは特定の時刻における状態を指定する条件である  

<a id="source-L288"></a>波動方程式は2階なので、初期条件が２ついる  


<a id="source-L291"></a>・依存領域、影響領域、伝播速度  
<a id="source-L292"></a>ダランベールの波動公式を見ると、上半平面の任意の点を任意に固定したとき、その点でのuの値は区間とct0だけの距離内にある点に依存して初期値とは一切関係ない  
<a id="source-L293"></a>この区間を依存領域という  
<a id="source-L294"></a>逆にx軸上の点を固定すると、この点での初期値によってuの値が変換する集合は影響領域という  
<a id="source-L295"></a>波動方程式について初期値の伝播速度はcであると言える

### 1.3 R^nにおける初期値問題

<a id="source-L300"></a>空間変数xの属する空間の次元を1より大きいnとすると難しくなるが、xが動く範囲が全空間R^nである場合はやや単純で比較的容易に扱うことができる  
<a id="source-L301"></a>具体的には、Fourier変換を用いて初期値問題の解を得ることができる  
<a id="source-L302"></a>Fourier変換は無限領域における積分で定義されるので積分の収束を真面目に問題にするとかなり面倒だが、ここではその点には目を瞑って形式的計算議論をする  

<a id="source-L304"></a>・Duhamelの原理  
<a id="source-L305"></a>非同次の初期値問題を解くために、その特別な場合である３つの初期値問題を考える  

<a id="source-L307"></a>・Fourier変換による解の表示  
<a id="source-L308"></a>Fourier変換は非常に強力だが、広義積分で定義されていて、厳密な扱いが少し難しいのでこの講義ではあまり扱わないことにする  


<a id="source-L311"></a>・R^2, R^3における初期値問題の解の簡単な公式  
<a id="source-L312"></a>Fourier変換を用いた解の公式では解の性質を調べるには若干使いにくいところがあるので、よりわかりやすい解の公式を紹介する  

<a id="source-L314"></a>・Huygensの原理  
<a id="source-L315"></a>波動方程式の解は空間の次元によって性質がずいぶんと異なる

### 1.4 初期境界値問題

<a id="source-L321"></a>障害物のない波動現象はつまらないので、初期値境界値問題を考える  

<a id="source-L323"></a>・問題の設定  
<a id="source-L324"></a>有限区間における波動方程式の問題を考える  
<a id="source-L325"></a>解を１つに定めるには初期条件だけでは不十分で、境界条件と呼ばれる条件を指定することが多い  
<a id="source-L326"></a>初期条件と境界条件を満たす微分方程式の解を求めよという問題を初期値境界値問題という  

<a id="source-L328"></a>・解の存在  
<a id="source-L329"></a>この問題の解の存在については、Fourierの方法を用いて解が構成できる  

<a id="source-L331"></a>・解の一意性  
<a id="source-L332"></a>波動方程式の解の一意性の証明にはエネルギーを導入してその保存則を利用する  
<a id="source-L333"></a>証明は全く数学的であるが、物理的な意味を持つ補助関数を導入するところが面白い  

<a id="source-L335"></a>熱伝導方程式の古典解の一意性を証明するために最大値原理を導入するが、波動方程式については最大値原理のような定理は存在しない

### 2.3 初期値境界値問題、適切性

<a id="source-L355"></a>・定式化  

<a id="source-L357"></a>・適切性  
<a id="source-L358"></a>アダマールは適切性という概念の重要性を提唱した  
<a id="source-L359"></a>問題が適切であるとは、問題の解が一意的に存在しかつ解がデータに連続的に依存することである  

<a id="source-L361"></a>・古典解  
<a id="source-L362"></a>適切性の議論をするために考察する対象とする解を明確に定義する必要がある  
<a id="source-L363"></a>偏微分方程式は難しいので、解の存在を示すためにしばしば次のような論法を使う  
<a id="source-L364"></a>まず、もとの方程式の意味を緩めた弱解または広義解を求めて、後からそれが元の方程式を満たすことをチェックする  
<a id="source-L365"></a>常微分方程式の問題の適切性を示すのは簡単だが（一般的な定理がある）、偏微分方程式の問題の適切性を示すのはかなり難しい  
<a id="source-L366"></a>一般的に議論するのは絶望的で、ここの偏微分方程式のタイプに応じた証明が必要になる  
<a id="source-L367"></a>１つの方程式の問題で、解の存在を示すための方法と解の一意性を示すための方法がまったく異なってしまうことも珍しくはない  
<a id="source-L368"></a>ここで考えている初期値強化一問題も、解の存在はFourierの方法で示せるが、一意性やデータに関する連続性は最大値原理という定理を用いる
