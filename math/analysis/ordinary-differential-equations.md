### 1.3 線形微分方程式

<a id="source-L21"></a>y’の一次とyの一次がある式  
<a id="source-L22"></a>また、yのゼロ次以下がない斉次線形微分方程式  
<a id="source-L23"></a>yのゼロ次があるのが非斉次線形微分方程式  

<a id="source-L25"></a>-斉次線形微分方程式  
<a id="source-L26"></a>一般解は変数分離  
<a id="source-L27"></a>線形性があるので、解の重ね合わせも解である  

<a id="source-L29"></a>-非斉次線形微分方程式  
<a id="source-L30"></a>q(x)があるので、変数分離できないので、斉次線形微分方程式の一般解 + 非斉次の特解  
<a id="source-L31"></a>特解は予測するのが良い  
<a id="source-L32"></a>もしくは定数変化法  
<a id="source-L33"></a>もしくはexp(P(x))をかけて積分するのがある  


<a id="source-L35"></a>

### 1.4 ベルヌーイの微分方程式

<a id="source-L36"></a>y’ + p(x)y = q(x)y^n  
<a id="source-L37"></a>という式  
<a id="source-L38"></a>uに対する非斉次線形微分方程式に帰着できる？  
<a id="source-L39"></a>u = y^(1-n)という置き換えがポイント  


<a id="source-L41"></a>

### 1.5 リッカチの微分方程式

<a id="source-L42"></a>y’ = p(x)y^2 + q(x)y + r(x)  
<a id="source-L43"></a>ベルヌーイでn=2として、yの0次の項も加えたもの  
<a id="source-L44"></a>(0)一般解を構成する一般的な手続きは知られていない  
<a id="source-L45"></a>(1)特殊解y0を使った一般解の構成法は知られている、y0が既知だとすると、 y = y0 + 1/u とおく  
<a id="source-L46"></a>すると、uについて非斉次線形微分方程式に帰着する  
<a id="source-L47"></a>見つかるならこんな形やろと思っておいてやることが大切例えば y0 = x^nなど  
<a id="source-L48"></a>(2)y0が見つからないときは、 y(x) = - 1/p(x) \* u’/u でuについて2階微分方程式にする  


<a id="source-L50"></a>

### 1.6 完全微分形

<a id="source-L51"></a>P(x,y)dx + Q(x,y)dy = 0で、∂p/∂y = ∂Q/∂xのもの  
<a id="source-L52"></a>両方積分してやれば良い  
<a id="source-L53"></a>完全微分形ではないが、積分因子をかけることで完全微分形になることがある  
<a id="source-L54"></a>例えば、熱力学では、dS = δQ/Tでは、1/Tが積分因子であると言えよう  

<a id="source-L56"></a>積分因子について  
<a id="source-L57"></a>積分因子を求める一般論は偏微分方程式になってしまうので現実的ではない  
<a id="source-L58"></a>(1)λ(x,y) = x^m\*y^nと改訂して調査  
<a id="source-L59"></a>(2)λ(x,y) = f(x) or g(y)のときもある  


<a id="source-L61"></a>

### 1.7 非正規形

<a id="source-L62"></a>正規形：y’ = f(x,y)でf(x,y)が滑らかな一価関数  
<a id="source-L63"></a>非正規形：そうではないもの全て、特異解を持つ場合がある  
<a id="source-L64"></a>例えば、(y’)^3 = 27y^2のときは、普通に累乗をとってしまうと、y=0の解がどうやっても表現できない  
<a id="source-L65"></a>これは特異解であるからである  
<a id="source-L66"></a>特異解は一般的に崩落線で与えられる  

<a id="source-L68"></a>・解の一意性  
<a id="source-L69"></a>y’ = f(x)が滑らかな一価関数であるとき、ある点を通過する解は唯一である  
<a id="source-L70"></a>非正規形のときは解が一意に決まるとは限らない  
<a id="source-L71"></a>例として、クレーローの微分方程式がある

### 「常微分方程式(Collatz)」


<a id="source-L135"></a>・グロンウォール不等式  

<a id="source-L137"></a>リプシッツ条件は、微分方程式を考える上ではある種の解の存在を担保するもの  
<a id="source-L138"></a>また、WeirestrassのMテストも解の存在を保証する  

<a id="source-L140"></a>グロンウォール不等式は解の一意性を担保する１つの主張である  


<a id="source-L143"></a>・WeierstarssのMテスト  
<a id="source-L144"></a>証明はほとんど明らか  

<a id="source-L146"></a>一様収束という条件はかなり強いので一様収束しているものは世の中少ない  

<a id="source-L148"></a>一般には少し緩めて広義一様収束を定義することがある  

<a id="source-L150"></a>fnというものを段階的に欲しい微分方程式の解に近づけていく  
<a id="source-L151"></a>全部含めたトータルの近似値というものを作り、それが関数になっているか、滑らかかなどを調べる  
<a id="source-L152"></a>とりあえず関数になっていることを議論するためにmテストがある  



<a id="source-L156"></a>・解の比較定理

<a id="source-L159"></a>これはとりあえず局所での解が存在するということしか言っておらず、解を延長できるかもしれない  
<a id="source-L160"></a>それについて議論していく  

<a id="source-L162"></a>微分可能性を見るときに、合成関数でかける形に分解していくのはよくある

<a id="source-L166"></a>よくわからないもののオーダーが評価できることが嬉しい  



<a id="source-L170"></a>・局所解の存在と一意性  

<a id="source-L172"></a>どういう状況設定に対して、どのような解が存在するかということを議論する

<a id="source-L176"></a>閉区間の長さがどのくらいなのかはわからない  


<a id="source-L179"></a>証明はピカールの逐次近似定理と呼ばれる

### 3 基本的な諸定理


<a id="source-L249"></a>（ホ）についての定理として、径数に関する解の連続性の定理がある

<a id="source-L255"></a>以上で疑問への解答は終わったが、まだいくつかの素朴な疑問が残っている  
<a id="source-L256"></a>その一つは差分方程式による方程式の近似の問題がある
