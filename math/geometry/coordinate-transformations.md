### 第1章 自然基底、反変ベクトル、計量テンソル



<a id="source-L28"></a>

### 1.1 自然基底と計量テンソル

<a id="source-L29"></a>リーマン幾何学で扱う座標系はデカルト座標系のように座標軸が直行しているような単純なものだけでなく、直線かつ斜交座標系や曲線座標系などどんな座標系でも良い  
<a id="source-L30"></a>実用的な曲線座標系では座標曲線が直交している直交座標系が多い  
<a id="source-L31"></a>また、リーマン幾何学では連続性が保証されている空間しか対象としていない  
<a id="source-L32"></a>各点の近傍で距離が明白に定義されていることがリーマン幾何学の大前提である  
<a id="source-L33"></a>こうした比較的自由な座標系の一点の座標を上付きサフィックスで表す  
<a id="source-L34"></a>また各点である特定の座標だけを1増加させた時の点の移動方向と移動距離を持つベクトルe\_mを定義し、それを基底ベクトルもしくは単に基底と呼ぶ  
<a id="source-L35"></a>移動が直線的でない場合、基底は微分の概念で定義される  
<a id="source-L36"></a>こうして全ての各座標変化に対応した基底がえられ、これを自然基底と呼ぶ  

<a id="source-L38"></a>座標系が歪んでいる可能性を持っていても、微小な２点を使ってベクトルという概念が定義できる  
<a id="source-L39"></a>線素ベクトルを定義する  

<a id="source-L41"></a>自然基底の単位にも、ベクトルの成分の単位にも色々ある  

<a id="source-L43"></a>リーマン幾何学ではたくさんのΣが使われるのでアインシュタイン規約という便利な記法を採用する  
<a id="source-L44"></a>これは同じサフィックスが上下に１つずつ現れるときには、総和記号を省略するというものである  

<a id="source-L46"></a>計量テンソルを定義する  
<a id="source-L47"></a>自然基底がいろいろな長さを持ちうる場合、線素がよく知られた形にはならない  
<a id="source-L48"></a>計量テンソルが自然基底の長さや非直交の補正をしている  
<a id="source-L49"></a>e\_mが実数ベクトルであるため計量テンソルは対称性がある  

<a id="source-L51"></a>空間の各点で定義された一般的なベクトルAは成分に展開できる  
<a id="source-L52"></a>これからベクトルの内積とういう概念が定義できる  

<a id="source-L54"></a>４つの例から、直交座標系におけるg\_mnの対角要素の平方根はかなり重要な量である  


<a id="source-L56"></a>

### 1.2 座標変換

<a id="source-L57"></a>元の座標系の上に貼られた別の座標をx^μ’とし、これらは元の座標系の座標の滑らかな関数で与えられるとする  

<a id="source-L59"></a>まずは全微分を元座標に対して得る  

<a id="source-L61"></a>dx^μ’とdx^mの関係が線型であるときその関係をアフィン変換という  
<a id="source-L62"></a>微分係数は場所によって緩やかに変化していくので局所的にはアフィン変換といえるが、対局的にはアフィン変換ではない  

<a id="source-L64"></a>元の座標系の成分から新しい座標系の成分へ変換することを順変換と呼び、ここに現れた∂を変換係数と呼ぶ  
<a id="source-L65"></a>この逆数も変換変数と呼ばれる  
<a id="source-L66"></a>この係数を便宜的に反変変換係数と呼ぶ  

<a id="source-L68"></a>この変換係数からなる行列はヤコビ行列とも呼ばれる  
<a id="source-L69"></a>逆変換は共変変数変換とよぶ  
<a id="source-L70"></a>以後の座標変換では２種類の変数変換が現れる  

<a id="source-L72"></a>ベクトルそのものは元の座標系でも新しい座標系でも不変である  

<a id="source-L74"></a>表現行列と似てるなあ  

<a id="source-L76"></a>ベクトルの座標変換の際、基底ベクトルの正正則と同じ変数係数、共変変数係数で順変換されることを共変と呼び、反変変換係数により変換されることを反変と呼ぶ  

<a id="source-L78"></a>リーマン幾何学では反変の量のサフィックスは上付きにし、共変の量のサフィックスは下付にするという規則がある  

<a id="source-L80"></a>g\_mnは2つのサフィックスに依存しているが、各サフィックスごとに自然基底と同じ共変変換係数を用いた変換を受ける  
<a id="source-L81"></a>一般に２つのサフィックスを持ち、それぞれがベクトルの成分と同様に変換される量を持つものをテンソルと呼ぶ  
<a id="source-L82"></a>g\_mnは２つのサフィックスとも共変変換を受けることから、テンソルの共変成分と呼ばれる  

<a id="source-L84"></a>球面座標系は、三次元空間に置かれた球面という部分空間の上で定義されている二次元座標系であり、この２つの空間の座標系の次元は明らかに異なる  
<a id="source-L85"></a>このような場合、次元の大きい方の座標系を大文字のサフィックスを用いて区別することとする  

<a id="source-L87"></a>部分空間がわに適切な独立な変数を追加すれば、相互に変換可能となる  




<a id="source-L91"></a>

### 1.3 反変ベクトル

<a id="source-L92"></a>任意のベクトルAの成分の変換則をもとめる  
<a id="source-L93"></a>ただし曲線座標系では２点間を結ぶ位置ベクトルのような長いベクトルは対象としない  
<a id="source-L94"></a>微小ベクトルや微分により得られるようなベクトルが対象である  

<a id="source-L96"></a>自然基底と同じ変換式に従うことを共変といって下付サフィックスをつけ、逆変換式に従うことを反変と言って上付きサフィックスをつける  
<a id="source-L97"></a>このため、A^mはベクトルAの反変成分と呼ばれ、上付きサフィックスを用いる  

<a id="source-L99"></a>内積は変換先でも同じ形で表現され、座標変換に対する不変量つまりスカラーとなっていることがわかる  

<a id="source-L101"></a>ある量の成分が２つのサフィックスで表現でき、かつその成分が２つの変換係数の積で変換できるとき、この量を２階のテンソルの成分とよぶ  

<a id="source-L103"></a>よくみる○の中に×があるのは直積と呼ばれる表示法であり、２つの基底の組みに絡んでいることと全体の変換係数がそれぞれの変換係数の積になることを示しているが、成分の変換式で表現する方がわかりやすいかもしれない

### 第2章 双対座標系


<a id="source-L110"></a>リーマン幾何学では、基底の長さが1とは限らないため計量てんそるが導入され、内積などの定義にそれが利用される  
<a id="source-L111"></a>こうした計算をさらに楽にするために導入されたのが双対座標系という概念である  


<a id="source-L113"></a>

### 2.1 双対基底

<a id="source-L114"></a>リーマン幾何学では、基底の長さが１とは限らない、このため、ベクトルの内積や長さの計算に計量テンソルが必要であった  
<a id="source-L115"></a>この面倒臭さを省くために導入されたのが双対基底という概念  
<a id="source-L116"></a>雰囲気を言えば、自然基底の逆数を長さに持つような基底である  

<a id="source-L118"></a>双対基底e^mは全て自然基底に直交した方向をとり、さらにe\_mの射影の逆数の長さを持つ  
<a id="source-L119"></a>この結果、e\_m・e\_nが必ずしもδとなることが保証されていなかった自然基底に対し、双対基底e^mを利用することにより、通常のベクトル空間と同様な式を確立することができた  

<a id="source-L121"></a>生成規則が反変的な基底なので上付きのサフィックスをつける  



<a id="source-L124"></a>

### 2.2 双対座標系の計量テンソル

<a id="source-L125"></a>双対基底からも新たな計量テンソルを定義することができる  
<a id="source-L126"></a>このg^mnの変換則は双対基底の変換則を利用して求めることができる  


<a id="source-L128"></a>

### 2.3 共変ベクトル

<a id="source-L129"></a>この双対基底を使って任意のベクトルを展開することを考える  
<a id="source-L130"></a>同じような手順で変換則が得られる  

<a id="source-L132"></a>∂^m\_nをm行n列の行列に対応させるとすると横ベクトルに対応させるべきである  


<a id="source-L134"></a>

### 2.4 降階、昇階と内積

<a id="source-L135"></a>計量テンソルの共変成分や反変成分には便利な機能がある  
<a id="source-L136"></a>それはベクトルやテンソルの共変や反変を自由に変更できること  
<a id="source-L137"></a>計量テンソルの共変成分を使うと、ベクトルの反変成分から共変成分を得ることができる  
<a id="source-L138"></a>上付きサフィックスを下付にしたことで、降階ともいう  
<a id="source-L139"></a>また、反変成分を使ってベクトルの共変成分から反変成分を得ることを昇階ともいう  

<a id="source-L141"></a>テンソルの共変成分、混合成分、反変成分はどれか１つがわかると他の成分は計算可能となる

### 第3章 共変微分


<a id="source-L146"></a>これまでの議論は固定した１点におけるベクトルやテンソルが座標変換によってどう変化するかについて行った  
<a id="source-L147"></a>したがって空間が曲がっていようが真っ直ぐだろうがあまり関係なかった  
<a id="source-L148"></a>ところが位置を移動し始めると空間の曲がりの影響が現れてくる  
<a id="source-L149"></a>こうした位置を移動したときベクトルやテンソルがどう変化するかについて論じる  
<a id="source-L150"></a>これらの微分も位置移動した結果の差分であるため位置微分に関する議論であるといっても良い  


<a id="source-L152"></a>

### 3.1 平行移動

<a id="source-L153"></a>リーマン幾何学では与えられた空間を移動することによるベクトルの変化が重要である  
<a id="source-L154"></a>例えば球面状でベクトルを平行移動して元の位置に戻しても平行になるとは限らない  

<a id="source-L156"></a>こうした議論を正確に行うにはベクトルの平行移動を厳密に定義しなくてはいけない  
<a id="source-L157"></a>どんな座標系でも対象とする点の近傍に限れば適切にやや多めの次元を持つ座標系を用意することにより歪の具合を綺麗に記述することができることが知られている  

<a id="source-L159"></a>はみ出しベクトルが対象とする座標系に垂直になるとき、平行移動されたベクトルであると定義する  
<a id="source-L160"></a>平行移動とは、わずかに離れた位置にベクトルをコピーしたその射影である  



<a id="source-L163"></a>

### 3.2 基底の平行移動と接続係数

<a id="source-L164"></a>基底もベクトルなので、平行移動ができる  
<a id="source-L165"></a>しかし移動さきの基底は別の原理で定義されているので、これらは一致しない  
<a id="source-L166"></a>以後、平行移動した基底と、その場所における基底の関係を式で調べてみる  


<a id="source-L169"></a>Γは局所的なアフィン変換を繋いでいく係数という意味で、アフィン接続係数または単に接続係数と呼ばれる  

<a id="source-L171"></a>この式を手がかりに次節で具体的な計算手法を得る  

<a id="source-L173"></a>なぜこんなややこしい量を導入しなければいけないかというと、例えば、ベクトルの微分を行うときにはx+dxの量の処理をxにおいて行うことになる  
<a id="source-L174"></a>そのとき、基底として、em(x+dx)を用いると、得られた結果は対象としている空間を飛び出してしまい同じ空間ないで処理d系なくなってしまう  
<a id="source-L175"></a>これを避けるには垂直の基底を使うのが良い  
<a id="source-L176"></a>そのためにこの平行移動した基底を容易に得られるようにしておく必要がある  



<a id="source-L179"></a>

### 3.3 計量テンソルと接続係数

<a id="source-L180"></a>接続係数Γは高次元の直線座標系の情報が分かっていないと計算できず、かなり不便である  
<a id="source-L181"></a>幸い、接続係数の値は部分空間の曲線座標系の計量テンソルから計算可能である  
<a id="source-L182"></a>なお、接続係数の対称性を前提に議論を行う  


<a id="source-L184"></a>

### 3.4 空間変化するベクトル場と共変微分

<a id="source-L185"></a>重力場、電磁場などに代表されるベクトル場は場所と共にゆっくり変動する  
<a id="source-L186"></a>こうしたベクトル場の位置変動を調べよう  
<a id="source-L187"></a>一般ベクトルについても差分ベクトルをdA(x)とするのは問題がある  


<a id="source-L189"></a>
