# 次に考える問い

AIとの壁打ちを再開するための入口です。一度に一つを選び、説明と根拠はリンク先のノートで育てます。進め方は[壁打ちと更新の手順](../docs/learning-workflow.md)にあります。

## いまあるノートからの候補

以下は2026-09-20にAIが既存ノートから整理した候補です。本人が着手した記録や、優先順位を決めた一覧ではありません。

- **数学：基底の選び方で、数値計算の誤差はどう変わるか。** [基底変換のノート](../math/linear-maps-and-matrices.md)の「次の問い」から。最初の一歩は、同じ写像を二つの基底で表し、入力の小さな変化が座標にどう現れるかを比較すること。
- **物理：保存則の残差が小さければ、解の誤差も小さいのか。** [保存則と構成式のノート](../physics/conservation-and-constitutive-laws.md)の「次に確かめたいこと」から。最初の一歩は、方程式だけでなく初期条件を満たすかを、ばねの例で分けて確認すること。
- **化学：濃度が一定の状態と、平衡はどう違うか。** [平衡と速度のノート](../chemistry/reaction-direction-and-rate.md)の開放系への話題から。最初の一歩は、流入・流出のある物質収支を書き、反応が続いていても濃度が一定になる条件を調べること。

候補は少数に保ちます。各ノートの「残った問い」が詳細の置き場所です。一区切りついたらノートへ結果と次の一歩を残し、この一覧を入れ替えます。
